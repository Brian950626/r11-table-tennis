# R-11 桌球對決

在瀏覽器裡跟機器人 R-11 打一局 11 分制桌球。手機、平板、電腦都能玩，不用安裝任何東西。對手有八種動漫風造型可以選，每個造型的打法都不一樣：經典（均衡）、櫻（愛放短）、焰（愛扣殺）、喵喵（變化多端）、影（愛打大角度）、靜（穩定不失誤）、颯（快攻）、眠（高吊守備）。

## 怎麼玩

用瀏覽器打開 `index.html` 就能玩。開啟 GitHub Pages 之後，也可以直接用網址玩。

| 動作 | 怎麼做 |
| --- | --- |
| 移動球拍 | 手機／平板在畫面上拖曳；電腦用滑鼠，或方向鍵／WASD |
| 打左右 | 擊球瞬間往左或往右移動，球就往那邊飛 |
| 扣殺 | 擊球瞬間用力往前推（球彈得夠高時，球外圈會出現黃色光圈） |
| 放短 | 擊球瞬間用力往後拉，球會落在網前 |
| 完美時機 | 球落台彈起來、快到最高點（還在上升）時打到：落點不會偏、球更快、一定打在桌上，來球的旋轉也不影響，R-11 比較難接。簡單和普通難度會用準星標出最佳擊球點，往前或往後站去對準它；球外面出現亮圈時就是完美時機。太早或太晚，畫面會告訴你 |
| 擋球 | 拍子不動去擋快球：借來球的力量回去，球比較短、比較穩，來球的旋轉卸掉一半 |
| 上旋 | 擊球瞬間輕輕往前推：過網後往下墜，落到對面桌上被桌面往前推，彈得低、比落台前還快（球砸得越重加速越多） |
| 下旋 | 擊球瞬間輕輕往後拉：落台時被桌面往後拖，彈得低、明顯變慢 |
| 側旋 | 擊球瞬間往右揮＝右側旋、往左揮＝左側旋：球在空中往揮的方向彎，落台後再往那邊拐，揮得越快側旋越強。平著橫揮會帶一點上旋，往後拉同時橫揮是側下旋 |
| 打球的側面 | 球偏在拍子中心的右邊＝拍子摩擦到球的左側，球往右彎；偏在左邊＝摩擦到球的右側，球往左彎。拍子動得越快側旋越強；打在跟揮拍方向相反的那一側，側旋會被抵消甚至反過來 |
| 力量 | 往前推得越快，球飛得越快；超過一定速度就是扣殺 |
| 拉球（引拍） | 擊球前先往後拉，再往前揮：上旋更強，引拍越長、揮得越快越強。從斜後方斜著往前揮＝側上旋（上旋夾帶側旋） |
| 擦邊 | 球從拍子外面一小圈經過也算打到，但打在拍子邊緣：球變慢、往打到的那一側歪掉、高度不穩，旋轉大多傳不過去 |
| 接旋轉球 | 看球的顏色：紅色是上旋，平擊回球容易出界，輕拉化解；青色是下旋，平擊容易掛網，輕推化解；紫色是側旋，回球會往旁邊偏；外圈一半紅（或青）一半紫是側上旋（或側下旋） |
| 發球 | 左右移動瞄準，站離桌子越遠發越長；按「發球」或空白鍵 |
| 換造型 | 開始選單或暫停時，點選「對手造型」 |
| 暫停 | 右上角按鈕，或 Esc |

### 雙人對戰

開始選單的「模式」選「雙人對戰」，兩個人在同一台裝置上互打，畫面改成從球桌正上方往下看。

| 裝置 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 手機直拿（平放在兩人中間） | 拖曳下半邊畫面，點一下自己那半邊發球 | 拖曳上半邊畫面（分數、提示會轉 180 度給他看），點一下發球 |
| 電腦（球桌橫放） | 左邊，WASD 移動、空白鍵發球 | 右邊，方向鍵移動、Enter 發球 |

兩根手指可以同時拖曳。方向照螢幕：往網子推＝扣殺、往後拉＝放短。難度在雙人模式變成「球速」。

規則跟正式桌球一樣：先拿 11 分且領先 2 分獲勝；每 2 分換發球，10:10 之後每分換；發球要先在自己這邊彈一次再過網，擦網後落在對面就重發。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 遊戲畫面：球桌與機器人繪製、觸控／滑鼠／鍵盤操控、音效、選單、計分板 |
| `engine.js` | 遊戲引擎：球的物理（重力、桌面反彈、網、旋轉）、比賽規則、機器人 AI。不碰畫面 |
| `skins.js` | 對手造型：每個角色的頭髮、衣服、表情怎麼畫，以及它的打法 |
| `rules.test.js` | 規則測試：出界、掛網、漏接、發球順序、Deuce、擦網重發 |
| `spin.test.js` | 旋轉測試：上旋、下旋、側旋的飛行和落台（上旋加速、下旋減速），擊球手勢、引拍、打在球的哪一側打出的旋轉，擦邊，完美時機和擋球，接旋轉球的影響 |
| `selfplay.test.js` | 自動對打測試：測試機器人對每個造型的打法在三種難度各打 20 局，確認每局都能打完、難度有差、R-11 越難越常打旋轉球 |
| `skins.test.js` | 造型測試：每個造型的每種表情都畫一遍，確認不會出錯、不會畫到被計分板擋住的地方 |
| `records.js` | 成績紀錄：每局結果、勝率、連勝、排行榜，存在這台裝置的瀏覽器裡 |
| `records.test.js` | 成績測試：勝率和連勝的計算、資料壞掉時不會出錯 |
| `package.json` | 讓 `npm test` 可以一次跑完所有測試 |

想調整難度，改 `engine.js` 最上面的 `DIFFS`：`ts` 是遊戲速度，`rReact` 是機器人的反應時間（秒），`rErr` 是基本失誤率，`smash` 是扣殺機率，`spin` 是一般回球帶旋轉的機率，`rSpinErr` 是 R-11 接到旋轉球時多出的失誤率，`perfect` 是完美時機的寬度（秒），`sweet` 是要不要顯示最佳擊球點的準星。旋轉本身的強弱（彎多少、落台加速或減速多少、落台偏多少、接球偏多少）在 `SPINFX`。每個造型的打法個性在 `DIFFS` 下面的 `STYLES`，會疊在難度上（例如「愛扣殺」把扣殺機率調高、失誤也變多）。

## 跑測試

需要先安裝 [Node.js](https://nodejs.org/)（不需要安裝其他套件）：

```
npm test
```

看到五次「全部通過」就代表規則、旋轉、難度、造型和成績紀錄都正常。**改過 `engine.js` 或 `skins.js` 一定要跑一次。** 推上 GitHub 後，Actions 也會自動跑，Pull Request 頁面會顯示綠勾或紅叉。

## 新增造型

造型全部在 `skins.js`，不用改其他檔案：

1. 複製一個現有的 `person({...})`（例如 `classic`），改掉 `id`（英文、不能跟別人重複）、`name`（選單上顯示的短名字）、`title` 和 `desc`。
   `style` 選一個 `engine.js` 裡 `STYLES` 的打法，`desc` 要寫出來，例如「打法「愛扣殺」：……」。
2. 改顏色、`bangs`（瀏海）、`locks`（側髮）和 `outfit`（衣服）的畫法；身體後面的東西（後髮、馬尾、尾巴、圍巾）寫在 `back`，眼鏡、髮飾寫在 `front`。座標單位是公分、y 朝下，頭的中心大約在 y = -64，不要畫到 y = -104 以上（會被計分板擋到）。
3. 眼睛、眉毛、嘴巴的表情（平常、眨眼、專注、得分、失分、發球）由共用的畫法處理，用 `eye`、`mouth` 設定眼型和嘴型就好；檔案最上面有每個表情參數的說明。
4. 把新造型加進檔案最下面的 `LIST`，打開 `index.html` 選選看。
5. 跑 `npm test`，確認造型測試全部通過。

## 用 Claude Code 開發

在這個資料夾打開 Claude Code，它會自動讀 `CLAUDE.md`，裡面寫了這個專案的規定：檔案分工、座標、測試和 Git 流程。另外有兩個指令：

- `/new-skin 造型描述`：照規定新增一個造型，並跑完測試
- `/pr-ready`：發 Pull Request 前檢查測試和規定，並寫好 PR 說明

`.claude/settings.json` 讓 Claude Code 跑測試、開分支、commit 時不用一直問，但 `git push` 一定會先問你。想再調整成自己的習慣，就改 `.claude/settings.local.json`，這個檔案只在你自己的電腦上，不會上傳。

## 一起開發的流程

1. 想做什麼先開一個 **Issue**（例如「加入下旋球」），在裡面說你要做，避免兩個人做同一件事。
2. 開一個新分支，不要直接改 `main`：`git checkout -b add-backspin`
3. 改完、跑完 `npm test`，再 commit 並 push 你的分支。
4. 在 GitHub 上開 **Pull Request**，寫清楚改了什麼、怎麼測的。
5. 另一個人看過、在手機或電腦上實際玩過沒問題，再按 Merge。

一個 Pull Request 只做一件事，比較好審查，出問題也容易退回。
